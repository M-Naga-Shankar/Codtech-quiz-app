# Codtech-quiz-app

🛠️ Technologies Used

    HTML5

    CSS3

    JavaScript (Vanilla)

    Bootstrap 5

    Font Awesome (optional for icons)

📦 Installation

    Clone the repository

git clone https://github.com/your-username/quiz-app.git

    Navigate to the project folder

cd quiz-app

    Open the project

Just open index.html in your browser:

start index.html

💻 Usage

    Click on the correct answer from the given options.

    Get instant feedback—green for correct, red for incorrect.

    Click Next to proceed.

    See your final score at the end and choose to restart.

🧩 Customization

You can easily add your own questions by modifying the questions array in script.js:

const questions = [
  {
    question: "Your question here",
    options: ["Option1", "Option2", "Option3", "Option4"],
    answer: "Correct Answer"
  }
];
